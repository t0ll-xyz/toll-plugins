# toll-plugins

SDKs and agent plugins for [Toll](https://t0ll.xyz/agents): coin checks read from the chain
(Robinhood Chain, Solana, BSC) over Toll's remote MCP server.

- `packages/sdk-js` - `@t0ll/sdk` (TypeScript)
- `packages/sdk-py` - `toll-sdk` (Python, import `toll`)
